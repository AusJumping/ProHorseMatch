You want to link users to devices so you can send targeted alerts.
Prompt:
When a user grants push notification permission via OneSignal:

1. Capture the OneSignal Player ID (subscription ID).
2. Send it to the backend via a POST request.
3. Store it in PostgreSQL linked to the logged-in user's ID.

Backend:
- Create a route POST /api/users/push-subscription
- Save fields:

    onesignalPlayerId
