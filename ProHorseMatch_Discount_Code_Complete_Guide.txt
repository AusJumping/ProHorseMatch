3. DATABASE SCHEMA
=======================================================================

DISCOUNT_CODES TABLE:
CREATE TABLE discount_codes (
  id SERIAL PRIMARY KEY,
  code TEXT NOT NULL UNIQUE,
  description TEXT,
  discount_type TEXT NOT NULL,
  discount_value INTEGER NOT NULL,
  max_uses INTEGER,
  used_count INTEGER DEFAULT 0,
  active BOOLEAN DEFAULT true,
  valid_from TIMESTAMP DEFAULT NOW(),
  valid_until TIMESTAMP,
  applicable_plans TEXT[],
  created_at TIMESTAMP DEFAULT NOW()
);

DISCOUNT_CODE_USAGE TABLE:
CREATE TABLE discount_code_usage (
  id SERIAL PRIMARY KEY,
  discount_code_id INTEGER REFERENCES discount_codes(id),
  user_id INTEGER REFERENCES users(id),
  used_at TIMESTAMP DEFAULT NOW(),
  subscription_id TEXT
);

FIELD DESCRIPTIONS:
- discount_type: 'percentage', 'months_free', 'fixed_amount'
- discount_value: 0-100 for percentage, 1-12 for months, cents for fixed amount
- max_uses: NULL for unlimited uses
- applicable_plans: Array of plan types this code applies to

6. VALIDATION LOGIC
=======================================================================

The system validates discount codes based on these criteria:

1. CODE EXISTENCE
   - Code must exist in the database
   - Case-insensitive search (codes stored in uppercase)

2. ACTIVE STATUS
   - Code must have active = true

3. DATE VALIDITY
   - Current date must be >= valid_from (if set)
   - Current date must be <= valid_until (if set)

4. USAGE LIMITS
   - If max_uses is set, used_count must be < max_uses
   - If max_uses is NULL, unlimited usage allowed

5. USER USAGE
   - User cannot use the same code twice
   - Checked via discount_code_usage table

6. PLAN APPLICABILITY
   - Code must be applicable to the selected subscription plan
   - Checked against applicable_plans array

8. FRONTEND INTEGRATION
=======================================================================

8.1 VALIDATE DISCOUNT CODE FUNCTION
const validateCode = async (code, planType) => {
  const response = await fetch('/api/discount-codes/validate', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ code, planType })
  });
  return response.json();
};

8.2 APPLY DISCOUNT CODE FUNCTION
const applyCode = async (discountCodeId, subscriptionId) => {
  const response = await fetch('/api/discount-codes/apply', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ discountCodeId, subscriptionId })
  });
  return response.json();
};

8.3 INTEGRATION WORKFLOW
1. User enters discount code in subscription form
2. Frontend validates code using validateCode()
3. If valid, show discount information to user
4. When user completes subscription, apply code using applyCode()
5. Handle success/error responses appropriately

10. SECURITY FEATURES
=======================================================================

1. CODE UNIQUENESS
   - All codes stored in uppercase
   - Database enforces unique constraint

2. ONE-TIME USE PER USER
   - Users cannot reuse the same discount code
   - Tracked via discount_code_usage table

3. USAGE TRACKING
   - All usage logged with timestamps and user IDs
   - Includes subscription ID for audit trail

4. PLAN VALIDATION
   - Codes only applicable to specific subscription plans
   - Prevents misuse across different plan types

5. AUTHENTICATION REQUIRED
   - All endpoints require user authentication
   - Prevents unauthorized access
