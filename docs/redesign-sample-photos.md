# Test horse photograph sources

These 30 photographs are used only by the explicit test-data preparation command,
which writes to the fixed redesign test hostname after checking that email, push,
payments and uploads are disabled. This module is not imported by the application
or production seeder. No photographs were added to the live database.

All source pages were individually checked for a free download and a link to the
[Pexels licence](https://www.pexels.com/license/). That licence permits free use
on websites and apps. These fictional profiles expressly state that stock photos
may show different horses; no real horse sale or photographer endorsement is implied.
Some photos include a rider or handler in an ordinary equestrian setting.
